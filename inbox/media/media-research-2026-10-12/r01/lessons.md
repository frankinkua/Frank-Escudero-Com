# Research Lessons Observed

* **Homonym & Identity Matching:** Searching for "Frank Escudero" alongside "Asombro Extremo" generated very few hits, reflecting that his recognized public identity in older press for this organization is almost exclusively "Ezequiel Escudero".
* **Tool Limitation & False Negatives:** The Google Search API returned "No results" for exact and relevant queries that in reality have corresponding high-quality articles (like the orchestrator-provided LA NACION article). This demonstrates that 11 null-URL queries from the search tool API do not justify comprehensive discovery or the absence of interviews. The actual tool response should be recorded as "Inconclusive".
* **Handling Conflict:** When dealing with historical press coverage profiling different co-founders (Marcos Amadeo vs. Julian Avila vs. Ezequiel Escudero), timelines and origin stories can conflict (e.g., meeting in 2014 vs. founding the company together in 2012). These conflicts must be preserved in the catalog rather than arbitrarily resolved.
* **Improved Prompt Clause:** "When search tools return generic 'No results' for established entities, explicitly log the outcome as inconclusive API limits rather than a verified absence of media. If an orchestrator provides a source, process it, extract the supported claims and conflict notes, and integrate it into findings."
