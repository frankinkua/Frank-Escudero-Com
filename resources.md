# Resources — what Frank actually uses

A practical list of the tools, reading, and open-source contributions behind
the site.

## Tools used daily
- **Reflex** — the Python web framework this very site runs on.
- **Tailscale** — tailnet for the home datacenter (box `100.115.209.119`).
- **Cloudflare Tunnel** (`cloudflared`) — zero-trust public ingress for
  `frank-escudero.com`.
- **olla LLM proxy** — the single model endpoint for the site's chat/restyle
  (`100.100.1.10:40114/olla/proxy/v1`, model `prism-ml/bonsai-27b`).
- **opencode / Claude Code / Gemini CLI / Jules** — agentic coding workflows.
- **uv + Python 3.13** — dependency and runtime management. SQLite — the site store.
- **KDE/Plasma + xrdp** — remote desktop into the box.
- **Git + GitHub** — everything is a commit; rollback is a `git checkout`.

## Self-hosted stack

- **HumHub** — community platform (used by InkuA's open organization model).
- **uptimeapp.de** — own monitoring platform for API performance/latency.
