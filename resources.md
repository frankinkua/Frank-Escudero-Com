# Resources — what Frank actually uses

A practical list of the tools, reading, and open-source contributions behind
the site.

## Tools used daily
- **Reflex** — the Python web framework this very site runs on.
- **Tailscale** — tailnet + Funnel for zero-trust public ingress.
- **LM Studio** — local LLM server (OpenAI-compatible `/v1`) hosting
  `prism-ml/bonsai-27b` for chat, greeting, filter and the worker agent.
- **opencode / Claude Code / Gemini CLI / Jules** — agentic coding workflows.
- **Ollama** — on-CPU local inference (models loaded in the box's VRAM).
- **uv + Python 3.13** — dependency and runtime management.
- **KDE/Plasma + xrdp** — remote desktop into the box.
- **Git** — everything is a commit; rollback is a `git reset`.

## Self-hosted stack
- **Nextcloud** — file sync and collaboration.
- **HumHub** — community platform (used by InkuA's open organization model).
- **uptimeapp.de** — own monitoring platform for API performance/latency.
